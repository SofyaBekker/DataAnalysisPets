# Аналитический дашборд: Погода в Новосибирске 2025-2026

## Описание проекта
Интерактивный дашборд в Yandex DataLens, визуализирующий климатические данные Новосибирска за год (18.09.2025 – 17.09.2026). Проект демонстрирует навыки работы с BI-инструментами, визуализации временных рядов и создания вычисляемых полей.

## Структура дашборда

### Блок 1: Погодный паспорт за год
- **Индикаторы:** максимальная (+32°C), средняя (+2.87°C) и минимальная (-40°C) температура; максимальные осадки в день (29 мм); количество дней с осадками (192)
- **Круговая диаграмма:** распределение осадков по интенсивности (без осадков — 186 дней, слабые — 149, умеренные — 28, сильные — 2)
- **Линейный график:** динамика показателей за год

### Блок 2: Месячная динамика
- **Линейный график:** распределение температуры по месяцам (день, ночь, средние значения)
- **Столбчатая диаграмма:** распределение осадков по месяцам с наложением климатической нормы

### Блок 3: Детализация по выбранному периоду
- **Интерактивный фильтр:** выбор диапазона дат
- **Индикаторы температуры:** средняя, максимальная, минимальная за выбранный период
- **Линейный график:** распределение температуры по времени суток (день/ночь) по дням
- **Индикаторы осадков:** общее количество осадков, количество дней с осадками
- **Круговая диаграмма:** распределение осадков по интенсивности за выбранный период
- **Столбчатая диаграмма:** распределение осадков по дням
